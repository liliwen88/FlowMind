## ⚡ 性能瓶颈

### 1. 递归深度问题 🔴 严重
- **位置**: parser.py::_parse_expression()
- **影响**: 深层嵌套表达式可能导致栈溢出
- **解决**: 添加递归深度限制或转换为迭代实现

### 2. copy.deepcopy 开销 🟡 中等
- **位置**: runner.py::run_flow()
- **影响**: 大型状态对象拷贝性能差
- **解决**: 使用浅拷贝或不可变数据结构
- **预期改进**: 30-50% 性能提升

### 3. 线性搜索符号表 🔵 轻微
- **位置**: validator.py
- **影响**: 大型 flow 文件查找效率低
- **解决**: 使用集合或字典优化查找
- **预期改进**: O(n) → O(1)
