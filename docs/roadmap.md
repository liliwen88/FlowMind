# Roadmap

## v0.1 (Foundation)

- Define grammar spec
- Parse and validate flow files
- Local runtime with step logs
- Golden-test harness

## v0.2 (Reliability)

- Retry/backoff primitives
- Fallback model routes
- Structured error taxonomy
- Replay mode for failed runs

## v0.3 (Adoption)

- More templates by domain
- CLI improvements
- Better docs and walkthroughs
- Simple flow visualizer

## v0.4 (Platform)

- Team config and policy packs
- Web trace viewer
- Approval center
- Hosted runtime option
